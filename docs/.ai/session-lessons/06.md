# ErgeMD Mermaid 图表主题适配 开发经验档案

> 会话日期：2026-05-04
> 技术栈：React 19 + Vite + Tauri 2 + Mermaid.js
> 任务目标：修复Mermaid思维导图中心节点文字颜色不跟随主题的问题，确保14款主题下文字清晰可读

## 1. 最终技术选型

| 维度            | 选型                           | 关键理由                                           | 被否决的替代方案及原因                               |
| --------------- | ------------------------------ | -------------------------------------------------- | ---------------------------------------------------- |
| Mermaid主题变量 | 使用 `themeVariables` 配置对象 | Mermaid不支持CSS变量，必须通过初始化配置注入颜色值 | 直接CSS样式覆盖 - Mermaid SVG渲染不支持外部CSS选择器 |
| 颜色配置结构    | `ChartColors` 接口 + 主题配置  | 统一管理14款主题的图表颜色，便于维护和扩展         | 硬编码颜色值 - 难以维护且无法跟随主题切换            |
| 中心节点文字色  | 专用 `centerText` 字段         | 分离背景色和文字色，确保对比度                     | 使用 `centerColor` 作为文字色 - 导致文字与背景同色   |

## 2. 核心架构决策

- **决策点**：思维导图中心节点文字颜色控制方案
  - **选择**：同时设置多个Mermaid变量（`mindmapTextColor`, `primaryTextColor`, `textColor`, `textColor0`, `cScaleInv0`）
  - **理由**：Mermaid内部使用多个变量控制不同场景的文字颜色，单一变量无法覆盖所有情况
  - **代价 / 约束**：需要维护多个变量的同步更新

- **决策点**：颜色配置抽象层次
  - **选择**：在主题配置中添加 `charts.mindmap` 对象，包含 `centerColor`, `centerText`, `level1Bg`, `level1Text` 等字段
  - **理由**：分离背景色和文字色配置，便于独立调整对比度
  - **代价 / 约束**：增加了配置复杂度

## 3. 关键代码模式（可复用片段）

### 3.1 Mermaid思维导图主题变量配置模式

**适用场景**：需要为Mermaid思维导图设置自定义主题颜色

**代码**：
```typescript
// 思维导图颜色配置接口
interface MindmapColors {
  centerColor: string;   // 中心节点背景色
  centerText: string;    // 中心节点文字色（关键！）
  branches: string[];    // 分支颜色数组
  level1Bg: string;
  level1Text: string;
  level2Bg: string;
  level2Text: string;
  level3Bg: string;
  level3Text: string;
}

// Mermaid变量注入（必须设置多个变量确保覆盖）
const vars = themeVariables as any;
vars.mindmapRootColor = mindmapColors.centerColor;
vars.mindmapTextColor = mindmapColors.centerText;
vars.primaryTextColor = mindmapColors.centerText;
vars.textColor = mindmapColors.centerText;
vars.textColor0 = mindmapColors.centerText;
vars.mindmapCenterBgColor = mindmapColors.centerColor;
vars.mindmapCenterTextColor = mindmapColors.centerText;
// 分支变量
vars["cScale0"] = mindmapColors.centerColor;
vars["cScaleInv0"] = mindmapColors.centerText;  // 关键：中心节点文字
```

**注意事项**：Mermaid内部使用多个变量控制文字颜色，必须同时设置所有相关变量才能确保生效

## 4. 踩坑记录（最高价值区）

### 坑 1：思维导图中心节点文字看不见

- **现象**：中心节点背景色正确，但文字颜色与背景色相同或对比度极低，无法阅读
- **根因**：Mermaid使用 `cScaleInv0` 变量控制中心节点文字颜色，而非 `primaryTextColor`；初始实现错误地将 `cScaleInv0` 设置为背景色
- **解法**：
  1. 在主题配置中添加 `centerText` 字段，专门设置中心节点文字颜色
  2. 设置 `vars["cScaleInv0"] = mindmapColors.centerText` 覆盖默认值
  3. 同时设置 `mindmapTextColor`、`primaryTextColor`、`textColor` 等变量作为冗余保障
- **预防**：配置颜色时，始终为背景色和文字色分别设置独立字段，确保对比度足够

### 坑 2：Mermaid主题变量命名不一致

- **现象**：设置了 `primaryTextColor` 但中心节点文字颜色未改变
- **根因**：Mermaid不同图表类型使用不同的变量名，思维导图使用 `mindmapTextColor` 和 `cScaleInv` 系列变量，而非通用的 `primaryTextColor`
- **解法**：针对思维导图类型，需要设置专门的变量：`mindmapRootColor`、`mindmapTextColor`、`mindmapMainColor`、`mindmapSecondaryColor`
- **预防**：配置Mermaid主题前，查阅官方文档确认目标图表类型支持的变量名

### 坑 3：主题切换后图表样式未更新

- **现象**：切换主题后，Mermaid图表颜色未跟随变化
- **根因**：Mermaid图表渲染后缓存了主题配置，需要重新渲染才能应用新主题
- **解法**：在主题切换时，强制重新渲染Mermaid组件（如通过key变化触发）
- **预防**：组件设计时考虑主题切换的重新渲染机制

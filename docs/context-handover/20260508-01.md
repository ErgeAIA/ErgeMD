## 2. 协作规则（本地 IDE 场景）

- AI 运行在本地 IDE 中，具备文件读写与终端执行能力。
- AI 的任何文件改动必须先经用户在 diff 视图中审核并 accept 后才生效。
- AI 不得在未明确授权的情况下执行：`git push`、`git commit --amend`、`rm -rf`、数据库迁移、部署命令、修改 CI 配置。
- AI 可运行只读命令（`ls`、`cat`、`git status`、`git diff`、`npm ls` 等）用于信息收集。
- AI 可运行构建与测试命令（`pnpm build`、`pnpm tauri dev` 等），但须在执行前声明意图，执行后如实报告退出码与关键输出。
- 每个阶段完成后，必须由用户在本地确认测试通过，AI 不得自行宣布"已修复"或"已完成"。
- 每次响应只处理一个阶段或一个聚焦问题。

**硬性规则**：
- 不输出与当前阶段无关的文件改动。
- 不将一个文件的代码混入另一个文件。
- 不跳过阶段。
- 生成一个阶段的产物后立即停止，等待用户验证反馈。
- 新建文件：允许输出完整内容。
- 修改既有高风险文件：必须使用最小精确补丁，禁止整文件重写。
- 每次文件操作必须清楚标注：操作类型 / 目标绝对路径 / 是否高风险。

## 3. 项目概述

**项目是什么**：ErgeMD 是一款专注于 Markdown 阅读的桌面应用，核心理念是极致的渲染美感 + 丝滑的阅读体验。

**主要用户或使用场景**：
- 技术文档阅读者
- 开发者阅读 README 和技术文档
- 需要长时间阅读 Markdown 格式文档的用户

**技术栈详情**：
| 层级 | 技术 | 版本 |
|------|------|------|
| 桌面框架 | Tauri 2 | >= 2.0 |
| 前端 | React 19 + TypeScript | React >= 19, TypeScript ~5.8 |
| 构建 | Vite | >= 7.0 |
| 状态管理 | Zustand | >= 5.0 |
| 样式 | Tailwind CSS 4 + CSS 变量 | Tailwind >= 4.0 |
| Markdown | react-markdown + remark/rehype | 最新 |
| 代码高亮 | highlight.js | ^11.11.1 |
| 数学公式 | KaTeX | ^0.16.44 |

| 后端 | Rust | edition 2021 |

**当前核心问题**：Mermaid 图表主题适配系统尚未完成，仅完成了 aurora 主题的配置。

**目标架构或目标行为**：实现所有 14 个主题的 Mermaid 图表完整配置，确保图表在不同主题下正确显示。

## 4. 已确认的决策

- **决策**：选择 Tauri 2 而非 Electron
  - **原因**：更小的安装包（~4MB vs ~100MB）、更好的性能、Rust 安全性
  - **状态**：已确认

- **决策**：选择 Zustand 而非 Redux
  - **原因**：更轻量、API 简洁、基于选择器的订阅机制
  - **状态**：已确认

- **决策**：选择 CSS 变量主题系统
  - **原因**：主题切换零重渲染、支持动态主题、与 Tailwind 兼容
  - **状态**：已确认

- **决策**：Mermaid 主题通过 CSS 变量映射
  - **原因**：与现有主题系统统一、支持动态切换、无需单独 JS 配置文件
  - **状态**：已确认

- **决策**：统一项目文档入口为 AGENTS.md
  - **原因**：将 CLAUDE.md 内容整合到 AGENTS.md，删除 CLAUDE.md
  - **状态**：已确认

## 5. 历史事件与硬性约束

| 事件 | 症状 | 根本原因 | 预防规则 |
|------|------|----------|----------|
| PowerShell Set-Content 损坏 UTF-8 中文 | 文件内容出现 `�` 乱码 | 外部命令绕过 diff 预览 + 隐式转码 | 写文件仅允许使用 SearchReplace 或 Write 工具 |
| 标题颜色未正确应用 | 主题切换时标题颜色未变化 | CSS 变量定义或选择器优先级问题 | 修改样式前先验证 CSS 变量定义和引用 |
| Mermaid 图表不适应主题 | 图表颜色与主题冲突 | 硬编码颜色值 | 所有 Mermaid 颜色通过 CSS 变量读取 |
| 大文件渲染性能问题 | 长文档滚动卡顿 | 全量渲染导致 DOM 节点过多 | 超过 500 行使用虚拟滚动 |

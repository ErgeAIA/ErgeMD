> 会话日期：2026-05-02T00:00

> 任务目标：修复 Mermaid 图表 PNG 导出功能，确保文字渲染和主题配色正确

## 1. 最终技术选型

| 维度         | 选型             | 关键理由                                 | 被否决的替代方案及原因                               |
| ------------ | ---------------- | ---------------------------------------- | ---------------------------------------------------- |
| PNG 导出方式 | 浏览器 Canvas    | 字体渲染正确，主题配色自然，无需额外依赖 | Rust 后端 (usvg/resvg)：字体加载困难，跨平台兼容性差 |
| 文件写入     | Tauri 自定义命令 | 绕过 Tauri 插件权限限制，更灵活          | @tauri-apps/plugin-fs：权限配置复杂，容易出错        |
| SVG 清理     | 前端预处理       | 防止 Tainted Canvas 错误                 | 后端清理：增加复杂度，延迟高                         |

## 2. 核心架构决策

- **决策点**：SVG 转 PNG 的实现位置
  - **选择**：浏览器端 Canvas 实现
  - **理由**：浏览器原生支持 SVG 渲染，字体、颜色、样式都能正确处理
  - **代价 / 约束**：需要处理 Tainted Canvas 问题，需清理 SVG 外部引用

- **决策点**：文件写入方式
  - **选择**：使用项目已有的 Tauri 命令
  - **理由**：绕过 Tauri 插件的严格权限控制
  - **代价 / 约束**：需额外维护后端命令

## 3. 关键代码模式（可复用片段）

### 3.1 SVG 清理（防止 Tainted Canvas）

**适用场景**：SVG 转 Canvas 前必须清理，否则会报安全错误

```typescript
function sanitizeSvgForCanvas(svgHtml: string): string {
  let clean = svgHtml;
  
  // 移除外部字体引用
  clean = clean.replace(/font-family:\s*['"][^'"]*['"]/g, 'font-family: "Arial", sans-serif');
  
  // 确保命名空间
  if (!clean.includes('xmlns="http://www.w3.org/2000/svg"')) {
    clean = clean.replace("<svg", '<svg xmlns="http://www.w3.org/2000/svg"');
  }
  
  // 移除外部链接
  clean = clean.replace(/<a[^>]*>/g, "");
  clean = clean.replace(/<\/a>/g, "");
  
  return clean;
}
```

**注意事项**：必须在创建 Canvas 前调用

### 3.2 SVG 转 PNG（浏览器端）

**适用场景**：需要将 SVG 导出为高质量 PNG

```typescript
async function svgToPng(svgHtml: string, scale: number = 2): Promise<Uint8Array> {
  const cleanSvg = sanitizeSvgForCanvas(svgHtml);
  const parser = new DOMParser();
  const doc = parser.parseFromString(cleanSvg, "image/svg+xml");
  const svg = doc.querySelector("svg");
  
  // 获取尺寸
  let width = 800, height = 600;
  if (svg) {
    const viewBox = svg.getAttribute("viewBox");
    if (viewBox) {
      const parts = viewBox.split(/\s+/).map(Number);
      if (parts.length === 4) { width = parts[2]; height = parts[3]; }
    }
  }
  
  // Canvas 渲染
  const canvas = document.createElement("canvas");
  canvas.width = width * scale;
  canvas.height = height * scale;
  const ctx = canvas.getContext("2d")!;
  ctx.scale(scale, scale);
  
  const blob = new Blob([cleanSvg], { type: "image/svg+xml;charset=utf-8" });
  const url = URL.createObjectURL(blob);
  
  return new Promise((resolve, reject) => {
    const img = new Image();
    img.onload = () => {
      ctx.drawImage(img, 0, 0, width, height);
      canvas.toBlob(blob => {
        URL.revokeObjectURL(url);
        if (blob) {
          const reader = new FileReader();
          reader.onload = () => resolve(new Uint8Array(reader.result as ArrayBuffer));
          reader.readAsArrayBuffer(blob);
        }
      }, "image/png", 1.0);
    };
    img.src = url;
  });
}
```

**注意事项**：返回 Uint8Array，需配合二进制写入命令

#[tauri::command]
pub async fn write_binary_file(path: String, content: Vec<u8>) -> Result<(), String> {

## 4. 踩坑记录（最高价值区）

### 坑 1：Tauri 插件权限限制

- **现象**：`fs.write_file not allowed` 错误
- **根因**：@tauri-apps/plugin-fs 有严格的权限配置，默认不允许写入任意路径
- **解法**：改用项目自定义的 Tauri 命令（`write_file`, `write_binary_file`）
- **预防**：文件 IO 优先使用项目已有命令，避免引入新插件

### 坑 2：Rust 后端 SVG 文字缺失

- **现象**：PNG 导出后文字没有渲染，只有图形
- **根因**：usvg 库的字体数据库未能正确加载系统字体
- **解法**：放弃后端方案，改用浏览器 Canvas 渲染
- **预防**：字体相关功能优先考虑浏览器实现

### 坑 3：Tainted Canvas 错误

- **现象**：`Failed to execute 'toBlob' on 'HTMLCanvasElement': Tainted canvases may not be exported`
- **根因**：SVG 中包含外部引用（如外部字体、图片、链接）
- **解法**：转 Canvas 前清理 SVG，移除外部引用
- **预防**：任何 SVG → Canvas 转换前必须调用清理函数

### 坑 4：TypeScript 类型错误

- **现象**：`类型"string"的参数不能赋给类型...`
- **根因**：`writeFile` 期望 Uint8Array 而非字符串
- **解法**：使用 `TextEncoder.encode()` 将字符串转为字节
- **预防**：仔细查看 API 文档，确认参数类型

# ErgeMD 图片编辑功能开发经验档案

> 会话日期：2026-05-03T17:30
> 技术栈：React 19 / Vite 7 / Tailwind CSS 4 / TypeScript / Tauri 2
> 任务目标：为 Markdown 图片添加与链接相同的编辑功能，支持修改图片地址和替代文本

## 1. 最终技术选型

| 维度       | 选型                  | 关键理由                            | 被否决的替代方案及原因              |
| ---------- | --------------------- | ----------------------------------- | ----------------------------------- |
| 弹窗渲染   | React Portal          | inline 元素内不能直接渲染块级元素   | 直接渲染在组件内部 → HTML 结构错误  |
| 事件处理   | `e.stopPropagation()` | 防止右键事件冒泡到父级可交互元素    | 不阻止冒泡 → 点击菜单项触发链接跳转 |
| 编辑对话框 | 独立 Modal 组件       | 与 LinkEditModal 保持一致的 UI 风格 | 复用 LinkEditModal → 类型不匹配     |

## 2. 核心架构决策

- **决策点**：弹窗类组件必须使用 Portal 渲染
  - **选择**：创建通用 Portal 组件，将 ContextMenu 和 Modal 渲染到 document.body
  - **理由**：图片组件使用 `<span>` 包裹，不允许包含 `<div>` 子元素
  - **代价 / 约束**：需要额外创建和维护 Portal 组件

- **决策点**：右键菜单事件必须阻止冒泡
  - **选择**：在 handleContextMenu 中调用 `e.stopPropagation()`
  - **理由**：图片可能被 `<a>` 等可交互元素包裹，事件冒泡会触发父元素默认行为
  - **代价 / 约束**：需要在所有右键菜单处理函数中添加此调用

## 3. 关键代码模式（可复用片段）

### 3.1 React Portal 组件

**适用场景**：弹窗、菜单等需要脱离父组件层级渲染的场景

```tsx
import React, { useEffect, useState } from "react";
import { createPortal } from "react-dom";

interface PortalProps {
  children: React.ReactNode;
  container?: HTMLElement;
}

const Portal: React.FC<PortalProps> = ({ children, container }) => {
  const [mounted, setMounted] = useState(false);

  useEffect(() => {
    setMounted(true);
    return () => setMounted(false);
  }, []);

  if (!mounted) return null;
  return createPortal(children, container || document.body);
};
```

**注意事项**：确保在组件卸载前清理 Portal 内容，避免内存泄漏

### 3.2 右键菜单事件处理

**适用场景**：需要阻止事件冒泡的右键菜单

```tsx
const handleContextMenu = (e: React.MouseEvent) => {
  e.preventDefault();  // 阻止浏览器默认右键菜单
  e.stopPropagation(); // 阻止事件冒泡到父元素
  // ... 显示自定义菜单
};
```

**注意事项**：必须同时调用 preventDefault 和 stopPropagation

## 4. 踩坑记录（最高价值区）

### 坑 1：带链接图片右键控制台报错

- **现象**：控制台报错 `Warning: <div> cannot be a descendant of <p>`
- **根因**：ContextMenu 和 ImageEditModal 直接渲染在 `<span>` 内部，而 `<span>` 是 inline 元素，不允许包含 `<div>`
- **解法**：创建 Portal 组件，使用 `ReactDOM.createPortal` 将弹窗渲染到 `document.body`
- **预防**：所有弹窗类组件（菜单、模态框）都使用 Portal 渲染

### 坑 2：点击"编辑图片"跳转到链接

- **现象**：右键点击带链接图片，选择"编辑图片"后跳转到图片链接
- **根因**：右键事件冒泡到父级 `<a>` 元素，点击菜单项时触发链接跳转
- **解法**：在 `handleContextMenu` 中调用 `e.stopPropagation()` 阻止事件冒泡
- **预防**：在所有右键菜单处理函数中添加事件冒泡阻止

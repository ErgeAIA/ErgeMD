# ErgeMD 项目开发经验档案

> 会话日期：2026-05-04
> 技术栈：TypeScript / React 19.1.0 / Tauri 2 / Mermaid 11.14.0 / Zustand 5.0.12
> 任务目标：修复 Mermaid 图表显示问题，优化亮色主题配色（OKLCH）

---

## 1. 最终技术选型

| 维度             | 选型                           | 关键理由                           | 被否决的替代方案及原因                       |
| ---------------- | ------------------------------ | ---------------------------------- | -------------------------------------------- |
| 配色空间         | OKLCH                          | 感知均匀，色相稳定，对比度计算准确 | HEX/HSL：亮度不均匀，色相随明度漂移          |
| Mermaid 主题     | `base` 主题 + `themeVariables` | 只有 base 主题支持自定义变量       | `default`/`dark` 主题：不支持 themeVariables |
| 图表类型配置     | 按类型独立配置                 | 不同图表使用不同主题变量           | 统一配置：不生效                             |
| 亮色主题明度基准 | L ≈ 48%                        | 在白色背景上清晰可辨且不刺眼       | L 太高（如70%）对比度不足                    |
| 标题层级配色策略 | 色相间距 >= 50°                | 阅读器场景下层级区分明确           | 色相均匀分布不重要（用户确认）               |

## 2. 核心架构决策

- **决策点**：Mermaid 图表如何跟随主题切换
  - **选择**：使用 `base` 主题 + 动态修改 `themeVariables` + 缓存版本控制
  - **理由**：`base` 主题允许完全自定义颜色，同时图表类型需要独立处理
  - **代价/约束**：每次主题切换需清除缓存（更新版本号），部分图表（C4）不支持 themeVariables

- **决策点**：标题层级配色是否需要均匀分布
  - **选择**：间距 >= 50° 即可，不需要色相环均匀分布
  - **理由**：阅读器场景用户不会同时看到所有标题，颜色作用是区分层级而非色轮美观
  - **代价/约束**：紫色-粉色区域（H3-H4）间距仍偏近

- **决策点**：对比度标准
  - **选择**：正文 >= 4.5:1，标题 >= 4.5:1，次要文字 >= 3:1
  - **理由**：WCAG AA 标准，人眼舒适度优先
  - **代价/约束**：次要文字不能太浅，否则在白色背景上不可读

## 3. 关键代码模式（可复用片段）

### 3.1 Mermaid 图表主题动态配置

**适用场景**：根据亮/暗主题动态设置 Mermaid 图表颜色

```typescript
// 检测图表类型
const chartType = getChartType(mermaidCode); // 通过正则匹配 flowchart, sequenceDiagram, xychart 等

// 通用基础配置
const themeVariables = getMermaidThemeVariables(); // 从主题获取基础变量

// ★ 关键：必须使用 base 主题
const mermaidTheme = "base";

// 亮色主题必须设置
if (colors.isLight && isMindmap) {
  const vars = themeVariables as any;
  vars.darkMode = false; // ★ 关键设置
}

// 类型特定配置
if (isXychart) {
  const vars = themeVariables as any;
  vars.xyChart = {}; // ★ xychart 需要嵌套对象
  vars.xyChart.backgroundColor = colors.isLight ? "#FFFFFF" : "#1E1E2E";
}

if (isTimeline) {
  const vars = themeVariables as any;
  // ★ 时间线使用 cScale0-cScale11，不是 timelineGroupBg
  vars.cScale0 = colors.isLight ? "#C4B5FD" : "#4C1D95";
}
```

**注意事项**：
- `darkMode: false` 只在亮色主题需要
- `xyChart` 变量必须放在嵌套对象中
- 时间线图表用 `cScale*` 系列，不要用 `timelineGroupBg`

### 3.2 OKLCH 配色计算（亮色主题文本）

**适用场景**：计算符合 WCAG 对比度标准的文本颜色

```typescript
// 白色背景 (L=100%) 下文本 L 值与对比度关系：
// L=21%  → 对比度 10.3:1  (primary text)
// L=35%  → 对比度 4.5:1   (secondary text) ← 最低达标线
// L=48%  → 对比度 3.1:1   (muted text)   ← 3:1 最低线
// L=60%  → 对比度 2.0:1   (invalid)

// 亮色主题配色原则：
// - primary text: L 20-25%
// - secondary text: L 35-40%
// - muted text: L 50-55%
// - 强调色 L: 40-55% (白色背景清晰可辨)
```

### 3.3 CSS 变量 OKLCH 标注模式

**适用场景**：在 CSS 文件中记录颜色推导过程

```css
/* 注释格式：HEX值 + OKLCH值 + 对比度/用途说明 */
--text-primary: #333333; /* oklch(0.214 0 0) - 对比度 10.3:1 */
--h2-color: #2563EB; /* oklch(0.482 0.194 259.7) - 蓝色，与H3间距80° */
```

## 4. 踩坑记录（最高价值区）

### 坑 1：Mermaid 思维导图暗色主题配色不生效

- **现象**：设置了 `themeVariables`，但思维导图颜色完全没有变化
- **根因**：未设置 `darkMode: false`，Mermaid 的 `base` 主题默认是暗色风格，忽略亮色配置
- **解法**：在亮色主题配置中添加 `vars.darkMode = false`
- **预防**：只要使用 `base` 主题，亮色配置必须设置 `darkMode: false`

### 坑 2：Mermaid 时间线图表暗色主题背景为黑色

- **现象**：时间线在暗色主题下显示黑色背景
- **根因**：使用了错误变量名 `timelineGroupBg`，Mermaid 时间线使用 `cScale0-cScale11` 系列
- **解法**：
  ```typescript
  if (isTimeline) {
    const vars = themeVariables as any;
    vars.cScale0 = "#4C1D95"; // 深紫色
    vars.cScaleLabel0 = "#E4E4E8"; // 文字色
  }
  ```
- **预防**：配置 Mermaid 特殊图表前查阅官方文档，不要猜测变量名

### 坑 3：XY 图表配色在所有主题中相同（白色）

- **现象**：无论亮色/暗色主题，XY 图表都显示白色/灰色
- **根因**：`xychart` 类型需要使用嵌套的 `xyChart` 对象配置，不是扁平结构
- **解法**：
  ```typescript
  if (isXychart) {
    const vars = themeVariables as any;
    vars.xyChart = {}; // ★ 必须创建嵌套对象
    vars.xyChart.backgroundColor = colors.isLight ? "#FFFFFF" : "#1E1E2E";
  }
  ```
- **预防**：不同图表类型有不同的配置结构，XY图表、GitGraph、Timeline 都需要特殊处理

### 坑 4：`--text-secondary` 对比度不达标

- **现象**：浅色文字在白色背景上难以辨认
- **根因**：原始 `#666666` (L=41%) 对比度仅 2.8:1，未达到 WCAG 3:1 最低标准
- **解法**：将 `#666666` 改为 `#595959` (L=35%)，对比度提升至 4.5:1
- **预防**：所有文本颜色必须在提交前验证对比度

### 坑 5：标题层级 H2/H3 色相间距不足

- **现象**：H2(蓝) 和 H3(紫) 色相仅差 26.8°，视觉区分不明显
- **根因**：紫色 #6A1B9A (H=320°) 与蓝色 #1565C0 (H=265°) 色相太近
- **解法**：将 H3 改为粉色 #EC4899 (H=340°)，与 H2 间距 80°
- **预防**：设计标题配色时计算色相间距，确保 >= 50°

### 坑 6：ERROR_LOG.md 文件被覆盖

- **现象**：原有上千行错误经验文档被意外覆盖
- **根因**：使用 `Write` 创建新文件时未检查文件是否存在，直接覆盖
- **解法**：重要文档修改前先 `Read` 确认内容，使用 `Edit` 而非 `Write`
- **预防**：修改重要文件前先读取现有内容，保留备份

### 坑 7：C4 图表不支持 themeVariables

- **现象**：尝试通过 `themeVariables` 自定义 C4 图表样式无效
- **根因**：C4Context 图表类型不支持 `themeVariables`，必须在图表源码中使用 `UpdateElementStyle` 指令
- **解法**：
  ```mermaid
  C4Context
      Person(user, "用户")
      UpdateElementStyle(user, $fontColor="#1F2937", $bgColor="#E5E7EB")
  ```
- **预防**：不是所有 Mermaid 图表都支持 themeVariables，C4 必须用指令定义
